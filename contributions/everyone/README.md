# contributions/everyone/

Try it, break it, tell us what confused you. This is the lowest-effort,
highest-value folder - a precise "this confused me" is worth more than it
sounds.

## Everyone, phone or computer, same steps

1. Try the [browser playground](../../playground.py) or the
   [tutorial](../../docs/TUTORIAL.md) - no install needed for the playground.
2. Copy [`_template.md`](_template.md) and fill it in - even two lines is
   useful.
3. Submit it as a new file, e.g. `confusion-error-message.md`. Phone-only
   steps are in the [root README](../README.md).

That's the entire contribution. No code, no grammar knowledge needed.
