# contributions/ - start here if you're new

This folder exists so a first-time contributor never has to touch the core
engine to make a real contribution. Drop your work in the folder that matches
you below. A maintainer reviews it and, if it's ready, moves it into its real
home (`examples/`, `docs/`, `rust-engine/`, `sanskrita.py`) as part of merging
your pull request. Nothing you add here is final - it's a safe place to start.

- [`programmers/`](programmers/) - engine ideas, stdlib proposals, tooling, bug fixes
- [`scholars/`](scholars/) - grammar review, sandhi notes, glossary entries, meter notes
- [`teachers/`](teachers/) - example programs, lesson drafts, classroom feedback
- [`everyone/`](everyone/) - confusion reports, first-program notes, anything you tried

Each folder has its own `README.md` (what goes there) and a `_template` file
(copy it, fill it in, rename it to your topic).

## Never used GitHub before? Here's the whole thing, from zero.

You do **not** need a laptop, and you do **not** need to know Git or the
command line. Everything below works from a phone browser.

### 1. Make a GitHub account (2 minutes)

1. Open **github.com** in your phone's browser (or install the free **GitHub**
   app from the Play Store / App Store).
2. Tap **Sign up**. Enter an email, create a password, and pick a username
   (this becomes your public handle - anything is fine).
3. Verify your email (GitHub sends a code or a link).
4. Done - you now have an account. No payment, no personal details beyond
   email.

### 2. Find this project

1. Go to **github.com/BlackSparrow1506/sanskrita**.
2. Tap **contributions**, then the folder matching you
   (`programmers`, `scholars`, `teachers`, or `everyone`).

### 3. Add or edit a file, entirely from your phone

**To add a new file:**
1. Open the folder you picked.
2. Tap **Add file → Create new file** (top right, or the **+** menu).
3. Name your file (see that folder's README for naming - usually your topic
   or your name, e.g. `first-lesson-priya.md`).
4. Type or paste your content into the box.

**To edit an existing file** (like fixing a typo or improving the template):
1. Open the file.
2. Tap the **pencil (✏️) icon** in the top right.
3. Make your change.

**Then, for either case:**
1. Scroll to the bottom. Under "Commit changes," write one short line saying
   what you did (e.g. "add first lesson example").
2. GitHub will show an option: **"Create a new branch for this commit and
   start a pull request."** Select that (it's usually already selected).
3. Tap **Propose changes**, then **Create pull request** on the next screen.
4. That's it. You've opened a pull request - the standard way anyone
   contributes on GitHub. A maintainer will look at it, maybe suggest a
   small change, and merge it.

**Typing Devanagari on a phone:** turn on the Hindi/Sanskrit keyboard in
Gboard (Settings → System → Languages → add Hindi) - it types Devanagari
directly, including matras and conjuncts.
