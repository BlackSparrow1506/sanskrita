# contributions/teachers/

Example programs, lesson drafts, and classroom feedback. No prior coding
experience assumed - if you can read [the tutorial](../../docs/TUTORIAL.md),
you can contribute here.

## Everyone, phone or computer, same steps

1. Try [the tutorial](../../docs/TUTORIAL.md) yourself first (works in the
   browser playground, no install - link is in the main README).
2. Pick one:
   - **A new example or lesson** - copy [`_template.सं`](_template.सं) for a
     code example, or [`_template.md`](_template.md) for a written lesson.
   - **Classroom feedback** - if you taught this to students, write down
     what confused them, in [`_template.md`](_template.md).
3. Submit it as a new file named for the lesson, e.g.
   `lesson-loops-simple.सं`. Phone-only steps are in the
   [root README](../README.md).

Good examples get added to `examples/` and good lessons extend
`docs/TUTORIAL.md`, credited to you.
