# contributions/scholars/

Keyword grammar review, sandhi rules, glossary derivations, meter (chandas)
patterns. No programming needed - this is entirely about the Sanskrit.

## Everyone, phone or computer, same steps

1. Look at the existing glossary: [`docs/शब्दकोशः.md`](../../docs/शब्दकोशः.md)
   and grammar notes: [`docs/GRAMMAR.md`](../../docs/GRAMMAR.md).
2. Copy [`_template.md`](_template.md).
3. Write up one of:
   - a keyword you think is named or derived incorrectly, with your
     correction and reasoning,
   - a sandhi rule that's missing or wrong, with examples,
   - a new glossary entry for an undocumented term, **with its root and
     derivation** (required - see existing entries for the format),
   - a meter (chandas) pattern the engine doesn't recognize yet.
4. Submit it as a new file named for the term or topic, e.g.
   `glossary-vibhakti.md`. Phone-only steps are in the
   [root README](../README.md).

A maintainer or a programmer will fold accepted entries into the real
`docs/शब्दकोशः.md` or `docs/GRAMMAR.md`, with credit to you in the commit.
