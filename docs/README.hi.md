# ॐ संस्कृता (Sanskrita) v0.4 — फलम्

**संस्कृत में लिखी जाने वाली प्रोग्रामिंग भाषा।** देवनागरी कीवर्ड, पाणिनि के
कारक, बिलकुल सही दशमलव गणित, और एक तेज़ नेटिव इंजन।

> यह हिन्दी दस्तावेज़ है। अंग्रेज़ी संस्करण: [README.md](../README.md) ·
> पारिभाषिक शब्दकोश: [शब्दकोशः.md](शब्दकोशः.md) ·
> हर वादे का हिसाब: [STATUS.md](../STATUS.md)

## यह भाषा क्यों?

दुनिया की लगभग हर प्रोग्रामिंग भाषा अंग्रेज़ी शब्दों पर बनी है। यह अपने आप में
कोई कमी नहीं — अंग्रेज़ी ने प्रोग्रामिंग को दुनिया भर में पहुँचाया। पर सवाल यह
है: क्या देवनागरी पढ़ने वाला विद्यार्थी अपनी ही लिपि में कोड लिख सकता है?

संस्कृता का उत्तर है — **हाँ, और सिर्फ़ नाम बदलकर नहीं।** संस्कृत का व्याकरण
(विशेषतः कारक-व्यवस्था) प्रोग्रामिंग को कुछ ऐसा देता है जो और कहीं नहीं है।
साथ ही हमने Python और Java की जानी-मानी कमियों को शुरू से ही ठीक किया है।

यहाँ किसी भाषा की निंदा नहीं है। लक्ष्य केवल इतना है कि संस्कृता अपने बल पर
दुनिया की भाषाओं के बीच खड़ी हो सके।

## स्थापना (Install)

**आवश्यक:** Python 3.9+ — जाँचें: `python3 --version`

**macOS / Linux — दो आदेश:**

```bash
git clone https://github.com/BlackSparrow1506/sanskrita
cd sanskrita && bash install.sh
```

**Windows:**

```
python sanskrita.py examples\नमस्ते.सं
python playground.py
```

फिर कहीं से भी:

```bash
sanskrita examples/नमस्ते.सं          # प्रोग्राम चलाएँ  →  नमस्ते जगत्
sanskrita                             # REPL (सीधी बातचीत)
sanskrita --veg examples/नमस्ते.सं    # वही प्रोग्राम नेटिव वेगः इंजन पर
sanskrita-playground                  # ब्राउज़र प्लेग्राउंड
```

**जाँचें कि सब ठीक है:**

```bash
python3 परीक्षा.py     # अंत में आना चाहिए: सर्वं शुद्धम् ✓
python3 तुल्यता.py     # दोनों इंजन का आउटपुट अक्षरशः एक होना चाहिए
```

## पहला प्रोग्राम

```
वद("नमस्ते जगत्")।
```

बस इतना ही — कोई `public static void main` नहीं, कोई इम्पोर्ट नहीं।
हर वाक्य दण्ड `।` से समाप्त होता है, जैसे श्लोक की पंक्ति।

```
मानय नाम = "गौरी"।
मानय आयुः = २५।

यदि (आयुः >= १८) {
    वद(नाम, "मतदानं कर्तुं शक्नोति")।
} अन्यथा {
    वद(नाम, "अद्यापि लघुः")।
}

प्रत्येकम् इ इति परिधिः(१, ५) {
    वद(इ, "×", ७, "=", इ * ७)।
}
```

**रोमन में भी लिख सकते हैं** — हर कीवर्ड का रोमन उपनाम है और वह स्थायी है:

```
manay naam = "गौरी"|
yadi (5 > 3) { vad("अधिकम्")| }
```

`sanskrita --convert फ़ाइल` उसे देवनागरी में बदल देता है। **लिपि प्रस्तुति है,
अर्थ नहीं।**

## संस्कृता की अपनी विशेषता — कारक

किसी भी और भाषा में यह नहीं है। फ़ंक्शन के हर पैरामीटर को उसकी *व्याकरणिक
भूमिका* का नाम दिया जा सकता है, और फिर **क्रम मायने नहीं रखता**:

```
विधि प्रेषय(कर्ता प्रेषकः, कर्म सन्देशः, सम्प्रदान प्राप्तकर्ता) {
    वद(प्रेषकः, "→", प्राप्तकर्ता, ":", सन्देशः)।
}

# तीनों बुलावे एक ही अर्थ रखते हैं
प्रेषय(कर्ता: "रामः", कर्म: "नमस्ते", सम्प्रदान: "सीता")।
प्रेषय(कर्म: "नमस्ते", सम्प्रदान: "सीता", कर्ता: "रामः")।
प्रेषय(सम्प्रदान: "सीता", कर्ता: "रामः", कर्म: "नमस्ते")।
```

छह कारक: **कर्ता** (करने वाला), **कर्म** (जिस पर क्रिया हो), **करण** (साधन),
**सम्प्रदान** (जिसे दिया जाए), **अपादान** (जहाँ से), **अधिकरण** (कहाँ)।

गलत कारक देने पर इंजन तुरंत बताता है कि इस विधि के कारक कौन-से हैं।

---

## हमने Python और Java की कौन-सी कमियाँ ठीक कीं

| समस्या | संस्कृता का उत्तर |
|---|---|
| **`0.1 + 0.2 ≠ 0.3`** (हर भाषा में) | `०.१ + ०.२` ठीक `०.३` ही होता है — दशमलव बाइनरी फ़्लोट नहीं, सटीक दशमांश है |
| **NullPointerException** | टाइप वाला चर शून्यम् रख ही नहीं सकता, जब तक आप `नाम?` लिखकर अनुमति न दें |
| टाइप की गलती चलते-चलते पकड़ में आना | **प्राक्परीक्षा** — जो गलतियाँ सिद्ध हो सकती हैं वे प्रोग्राम चलने से *पहले* बता दी जाती हैं, और कुछ भी नहीं चलता |
| **इंडेंटेशन का अर्थ बदल देना** (Python) | `{ }` स्पष्ट हैं — सफ़ेद जगह से अर्थ कभी नहीं बदलता |
| **म्यूटेबल डिफ़ॉल्ट आर्ग्युमेंट** का चुपचाप बग | डिफ़ॉल्ट में *एक्सप्रेशन* रखा जाता है, हर बुलावे पर नया मूल्यांकन — यह बग हो ही नहीं सकता |
| समझ में न आने वाले एरर | हर एरर संस्कृत **और** अंग्रेज़ी में, पंक्ति संख्या और "क्या आपका मतलब … था?" सुझाव के साथ |
| Java का `public static void main` | `वद("नमस्ते")।` — पूरा प्रोग्राम |

### सटीकता बनाम रफ़्तार — आपकी मर्ज़ी

```
वद(०.१ + ०.२)।                                   # ०.३        (सटीक, डिफ़ॉल्ट)
वद(द्रुतदशमांशः(०.१) + द्रुतदशमांशः(०.२))।         # ०.३०००००००००००००००४
```

बाकी भाषाएँ बाइनरी फ़्लोट डिफ़ॉल्ट में देती हैं। संस्कृता उल्टा करती है: सटीक
दशमांश डिफ़ॉल्ट है, और तेज़ फ़्लोट **माँगने पर** मिलता है — और वह जो पकड़े हुए है
वही छापता है, कुछ छिपाता नहीं। पैसे-हिसाब में सटीकता चाहिए; ग्राफ़िक्स और ML में
रफ़्तार। नाम ही बता देता है कि आप क्या चुन रहे हैं: **द्रुत**, न कि **शुद्ध**।

## भाषा का ढाँचा — एक नज़र में

| काम | संस्कृता |
|---|---|
| चर / अचर | `मानय क = ५।` / `ध्रुव प = ३।` |
| शर्त | `यदि (…) { } अथ यदि (…) { } अन्यथा { }` |
| लूप | `यावत् (…) { }` · `प्रत्येकम् क इति सूची { }` |
| लूप रोकें / छोड़ें | `विरम।` / `अनुवर्त।` |
| विधि (function) | `विधि नाम(क, ख = ५) { फलम् क + ख। }` |
| सूची / कोश | `[१, २, ३]` / `{"नाम": "गौरी"}` — **गिनती १ से** |
| वर्ग (class) | `वर्गः नाम { विधि आरम्भ() { अयम्.क = १। } }`, `सृज नाम()` |
| त्रुटि सँभालना | `प्रयत { … } दोषे (त्रु) { … }` · अपनी त्रुटि: `क्षिप "सन्देशः"।` |
| आयात | `आनय "सूचीकर्म" इति सू।` · `आनय "python:numpy" इति सङ्ख्यात्मकम्।` |

## मानक पुस्तकालय (Standard Library)

```
आनय "गणितम्"     इति ग।    # वर्गमूलम्, घातः, ज्या, कोज्या, तलम्, पाई, ई
आनय "वाक्यकर्म"  इति व।    # विभज, संयोजय, खोज, प्रतिस्थापय, उच्च, परिष्कार
आनय "सूचीकर्म"   इति सू।   # छानय, प्रतिचित्रय, न्यूनीकरण, योगः, महत्तमम्
आनय "सञ्चिका"    इति स।    # पठ, लिख, योजय, अस्ति, पङ्क्तयः, सूचिका
आनय "जेसन"       इति ज।    # विश्लेषय, पाठय
आनय "कालः"       इति का।   # अद्य, संप्रति, वर्षः, क्षणविरामः
आनय "यादृच्छिकम्" इति य।    # अन्तरे, वरय, भिन्नम्
आनय "संस्कृतम्"   इति सं।   # अक्षराणि, मात्राः, छन्दः, रोमनय, संधय
```

**क्रियाओं की शृंखला** — जैसे संस्कृत में पद समास बनाते हैं, वैसे ही यहाँ
क्रियाएँ जुड़ती हैं:

```
वद(अङ्काः.छानय(विधि(क) { फलम् क > ५। })
         .प्रतिचित्रय(विधि(क) { फलम् क * क। })
         .योगः())।
```

### संस्कृतम् पुस्तकालय — दुनिया में अकेला

कोई और भाषा अपने भीतर संस्कृत भाषाविज्ञान लेकर नहीं आती:

```
आनय "संस्कृतम्" इति सं।
वद(सं.संधय("देव", "आलयः"))।      # देवालयः     — सन्धि
वद(सं.छन्दः("धर्मक्षेत्रे कुरुक्षेत्रे समवेता युयुत्सवः"))।   # अनुष्टुभ्  — छन्द पहचान
वद(सं.अक्षरगणना("नमस्ते"))।       # ३           — अक्षर गिनती
वद(सं.रोमनय("नमस्ते"))।            # namaste     — लिप्यन्तरण
```

इसी वजह से संस्कृता संगणकीय संस्कृत-अध्ययन के लिए दुनिया का सबसे सीधा औज़ार है।

## पाँच लाख पुस्तकालय, आज ही

```
आनय "python:math" इति गणितम्।
वद(गणितम्.sqrt(१६))।
```

Python का पूरा पारिस्थितिकी-तंत्र (NumPy, pandas, scikit-learn…) सीधे उपलब्ध है।
यह **शुरुआती सहारा** है, नींव नहीं — नेटिव वेगः इंजन जान-बूझकर `python:` आयात
स्वीकार नहीं करता और साफ़ बता देता है कि किस इंजन का प्रयोग करें।

## तीन तरीक़े, एक ही प्रोग्राम

```bash
sanskrita प्रोग्राम.सं            # संदर्भ इंजन — यही भाषा की परिभाषा है
sanskrita --veg प्रोग्राम.सं      # वेगः — नेटिव Rust इंजन, एक ही बाइनरी
sanskrita --druta प्रोग्राम.सं    # प्रयोगात्मक संकलित मोड — 1000×+ तेज़
```

रफ़्तार के बारे में हम ईमानदार हैं: संदर्भ इंजन Python पर बना ट्री-वॉकर है और
Python से तेज़ हो ही नहीं सकता — यही कारण है कि वेगः बनाया गया। असली माप
[BENCHMARKS.md](../BENCHMARKS.md) में हैं, अच्छे और बुरे दोनों आँकड़े।
